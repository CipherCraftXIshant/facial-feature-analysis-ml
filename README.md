# Facial Feature Analysis ML

A machine learning repository for facial feature analysis.

## Repository Structure

```
facial-feature-analysis-ml/
├── data/
│   ├── README.md
│   └── processed/
├── notebooks/
│   └── 01_setup_and_environment.ipynb
├── visualizations/
├── README.md
├── requirements.txt
└── .gitignore
```

## Setup Instructions

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Download Dataset:
   Instructions for downloading the UTKFace dataset via Kaggle API are provided in `notebooks/01_setup_and_environment.ipynb`.

3. Explore Notebooks:
   Open `notebooks/01_setup_and_environment.ipynb` to verify your environment setup and package versions.
